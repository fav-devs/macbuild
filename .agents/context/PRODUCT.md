# macbuild product context

## Register
Product: an operational dashboard and CLI for local Expo builds on a personal Mac.

## Users and purpose
The README describes developers using phones, Windows laptops, Linux servers, and agents to run builds on their Mac through a trusted tailnet. The Settings screen manages that Mac and its integrations. Native builds stay local; releases require explicit authorization.

## Interface principles
Follow the existing Settings components, vocabulary, and theme. Use direct labels, visible action results, and the existing error and empty-state patterns. Preserve native buttons, readable text, and accessible labels. Device access is revocable; credentials must not appear in device listings. Last activity must not imply a persistent online connection.
